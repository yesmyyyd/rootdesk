# 安装说明

## 环境要求
- Python 3.8.10
- Windows 系统

## 快速安装

```bash
# 进入客户端目录
cd 客户端

# 使用 requirements.txt 安装所有依赖（推荐）
pip install -r requirements.txt
```

## 分步安装（如果上面的失败）

### 1. 先安装核心 WebRTC 依赖（必须锁定版本）
```bash
pip install "aiortc==1.9.0" "cryptography==47.0.0" "pyOpenSSL==26.2.0" "aioice==0.9.0" "av==12.3.0" "pylibsrtp==0.10.0"
```

### 2. 安装屏幕捕捉相关
```bash
pip install "dxcam==0.0.5" "mss==9.0.2" "numpy==1.24.4" "pillow==10.4.0" "opencv-python==4.13.0.92"
```

### 3. 安装系统控制和 UI
```bash
pip install "PyAutoGUI==0.9.54" "PyQt5==5.15.11" "pystray==0.19.5"
```

### 4. 安装其他依赖
```bash
pip install "websocket-client==1.8.0" "requests==2.32.4" "psutil==7.2.2"
```


看到 "[+] 无参数初始化成功!" 说明环境配置正确！

## 常见问题

### "Unsupported key type" 错误
- 确保按照 requirements.txt 安装，特别是 cryptography 和 pyOpenSSL 的版本
- 如果仍然有问题，尝试：`pip install "cryptography==47.0.0" "pyOpenSSL==26.2.0" --force-reinstall`

### PyAudio 安装失败
- Windows 用户建议直接下载 whl 文件安装：https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio
- 或者使用：`pip install pipwin; pipwin install pyaudio`
